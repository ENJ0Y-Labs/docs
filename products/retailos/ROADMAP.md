# RetailOS Roadmap

- **Status:** Draft; priorities require product-owner approval.

## Now: Core Transaction Reliability

- Define and validate the core shopkeeper workflows.
- Establish consistent sale timestamps and Africa/Lagos daily reporting boundaries.
- Support physical products and services correctly.
- Implement base-unit inventory and product-specific selling units/prices.
- Validate stock availability and prevent overselling.
- Record payments, balances, and customer debt consistently.
- Consolidate sales history and transaction reporting.

## Next: Faster Daily Operations

- Return useful defaults for frequent products, quick-add services, default units, and recent customers.
- Improve product and customer search.
- Automate low-stock alerts.
- Improve sales reporting and payment-method filtering.

## Later: Operational Maturity

- Evaluate audit history and correction workflows.
- Improve onboarding and operational diagnostics.
- Validate backup, recovery, security, and reliability needs with real stores.

## Prioritization Notes

This roadmap is directional, not a release promise. Each item should have acceptance criteria, dependencies, an owner, and linked GitHub issues before work begins.
