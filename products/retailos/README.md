# RetailOS Documentation

RetailOS is Trexave's retail operations product. This directory is the canonical home for its product-level documentation.

## Documents

- [Product Requirements Document](PRD.md)
- [Roadmap](ROADMAP.md)
- [Requirements](REQUIREMENTS.md)

The PRD describes the problem, users, goals, and intended product behavior. The requirements document tracks testable requirements. The roadmap communicates planned sequencing. Implementation tasks should be tracked in GitHub Issues or Projects and linked to the relevant requirement.
