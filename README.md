## Documentation Principles

- Keep product behavior and acceptance criteria in product documentation.
- Keep implementation details close to the relevant codebase when they are repository-specific.
- Record important cross-cutting decisions in the appropriate `decisions/` directory.
- Update documentation when an approved change alters documented behavior.
